# Edinburgh Pub Review

An interactive map of Edinburgh pubs, built in R using Leaflet. Each Friday, 
my friends and I visit a new pub and rate it. This project visualises our 
reviews as an interactive map, with dot size and colour scaled by score.

## Features

- Interactive Leaflet map with searchable pub markers
- Dot size and colour (red–green gradient) scaled by pub rating
- Click any marker to see pub name and score
- Search bar to find pubs by name
- Scrollable and zoomable across Edinburgh (and beyond)

## Built With

- **Language:** R
- **Packages:** leaflet, leaflet.extras, RColorBrewer
- **Output:** Self-contained HTML widget
